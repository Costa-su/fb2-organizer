# FB2 Book Organizer & Renamer (PowerShell)

🌐 *Read this description in [English](README.md).*

Скрипт для автоматизации быстрой распаковки, интерактивного переименования, транслитерации и каталогизации электронных книг в формате **FB2**.

Проект разработан с упором на максимальную производительность. Для ускорения файловых и строковых операций стандартные командлеты PowerShell заменены на прямые вызовы нативных методов **.NET** (`StringBuilder`, `XmlDocument`, `FileIO`).

## 🚀 Основные возможности

*   **Ультра-быстрая распаковка:** Автоматически находит **ВСЕ(!)** `.zip` архивы в папке загрузок, мгновенно извлекает содержимое с помощью `.NET ZipFile` и отправляет обработанные архивы в Корзину. (*HINT* Не храните архивы кроме книжных в папке загрузки или измените папку для загрузки книжных архивов, или попробуйте изменить маску отбора с `*.zip`на `*.fb2.zip` в скрипте)
*   **Умное переименование по метаданным:** Парсит структуру XML внутри FB2-файлов для извлечения информации об авторе, названии книги, серии и номере книги в серии.
*   **Интерактивное разрешение конфликтов:** Если у книги указано несколько авторов, скрипт предложит удобное консольное меню для выбора нужного автора вручную. Ответ кэшируется для всей серии.
*   **Глубокая очистка данных:** Предотвращает дублирование информации (например, когда название серии дублируется внутри названия книги), вырезает лишнюю пунктуацию и формирует красивое имя через разделитель `_`.
*   **Конвертация чисел:** Проверяет название на повторение номера серии во всех вариантах: в обычных и римские цифрах, а также в виде порядковых текстовых числительных на русском языке (например, при номере в серии`21` -> `Название. Том двадцать первый` оставит только `Название`, а `Название. Том второй` останется без изменения).
*   **Транслитерация:** Переводит итоговое имя файла из кириллицы в латиницу (строго по символьной карте через `StringBuilder`) для совместимости с любыми файловыми системами. Символьную карту легко изменить под свои правила транслитерации (находится в файле `BookTools.psm1`)

## 🧱 Модульная архитектура (Самостоятельное использование)

Ключевой особенностью проектирования этого проекта является его **строгая модульность**. Основные рабочие скрипты намеренно разделены и спроектированы как **полностью независимые утилиты**. 

Вам не обязательно запускать весь конвейер обработки книг — вы можете использовать эти компоненты автономно в своих собственных сценариях:
*   **Инструмент безопасного удаления (`Protect-Remove`):** Может вызываться независимо из любой консоли PowerShell для безопасного удаления файлов и папок в Корзину Windows без всплывающих окон. Полностью поддерживает работу через конвейер (`ValueFromPipeline`).
*   **Парсер и переименователь книг (`Get-FictBookName`):** Может использоваться как отдельная функция для тестирования, предварительного просмотра или массового переименования метаданных FB2 совершенно отдельно от процедур распаковки и перемещения файлов.
(Не забудьте только подгрузить соответствующий модуль, например)
   ```powershell
   . "C:\Путь\К\fb2-book-organizer\bin\FictBookNaming.ps1"
   ```
## 📁 Структура репозитория

Проект организован так, чтобы работать «из коробки» на любом компьютере, используя относительные пути через `$PSScriptRoot`:

```text
fb2-book-organizer/
├── OrganizeBooks.ps1          # Главный исполняемый скрипт
├── LICENSE                    # Файл лицензии MIT
├── README.md                  # Документация (Английский)
├── README.ru.md               # Документация (Русский)
└── bin/                       # Папка внутренних модулей
    ├── MoveToRecycleBin.ps1   # Безопасное удаление в корзину (Protect-Remove)
    ├── FictBookNaming.ps1     # Утилиты конвертации строк, чисел и транслитерации
    └── BookTools.psm1         # Бинарный / структурный загрузчик модулей
```

## ⚙️ Настройка путей

Откройте файл `OrganizeBooks.ps1`, чтобы изменить целевые папки, если это необходимо:
*   `$Books` — Папка, куда скачиваются новые книги (по умолчанию `~\\Downloads`).
*   `$BooksLib` — Финальная папка вашей упорядоченной библиотеки (по умолчанию `~\\Books`).

*Путь к папке со служебными скриптами (`$BinPath`) определяется автоматически относительно расположения главного файла.*

## 🛠 Запуск проекта

1. Склонируйте или скачайте этот репозиторий в любую папку на компьютере.
2. Откройте консоль PowerShell и выполните основной скрипт:
   ```powershell
   & "C:\Путь\К\fb2-book-organizer\OrganizeBooks.ps1"
   ```

> **Примечание:** Для успешного переноса файлов в Корзину без всплывающих окон системы используется встроенная в Windows библиотека `Microsoft.VisualBasic`. Дополнительная установка внешних модулей или зависимостей не требуется.
